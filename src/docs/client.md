# 客户中心

首次访问默认显示简体中文。语言菜单可切换站点提供的语言，浏览器会记住选择。单语言站点始终显示配置的语言。

## 余额、账单与充值

界面使用 SHM 公布的账本币种，站点可用 CURRENCY 指定备用币种。如果两处都没有提供可识别的币种，界面显示「—」。人民币金额保留两位小数，符号放在数字前。账单日期按站点 TIMEZONE 显示，默认时区为 Asia/Shanghai。

在余额按钮中打开充值窗口，选择支付渠道并输入金额。每次打开都会读取当前账号可用的渠道。余额不足时，订购页以及欠费服务详情会显示需要补足的差额。扣款记录中的用量来自该笔扣款的结算记录，待结算和缺少最终读数会分别显示。

## 查看连接与订阅

打开已启用的代理或 VPN 服务时，首先显示「连接配置」。代理服务可查看订阅链接或二维码，也可按站点设置打开客户端。VPN 服务可下载配置文件。点击「刷新」会重新读取当前服务。

代理服务从 Storage 的 vpn_remna_<用户服务编号> 读取订阅，站点可设置 PROXY_STORAGE_PREFIX 更换前缀。VPN 配置使用 VPN_STORAGE_PREFIX，默认值为 vpn。「信息」页显示最近同步的用量、剩余流量、重置周期、有效期和设备限制。流量上限为零表示不限量。

## 分流

有分流权限的服务显示「分流配置」。填写出口原文，每行输入一条规则，点击「保存」启用。之后同一按钮可停用或重新启用配置。重新分配服务的服务器后，核对出口和规则并再次保存。待发布时，界面显示同步状态与服务端提供的预计时间。

在同一服务的标签之间切换会保留输入。关闭详情后再次进入，表单从当前账号的服务接口读取已保存的内容。写入超时会保留草稿并查询状态，需要再次提交时由用户点击按钮。

## 安装到主屏幕

首次符合安装条件时，浏览器会显示安装横幅。之后仍可打开站点的安装指引。
